# **README — utils**

This folder contains helper scripts used across the different ASR experiments in the repository.
These utilities support dataset preparation, SentencePiece tokenizer training, batch job management, and various workflow conveniences used during the afvoices, early-experiments, and kunkado training phases. The folder centralizes utility scripts so they don’t need to be duplicated across experiment folders. Anything here can be reused for new Bambara ASR experiments or adapted for future datasets.
