This folder contains the model and vocabulary files for a Sentencepiece tokenizer trained on Bambara text extracted [Transcription-Scorer](https://huggingface.co/datasets/RobotsMali/transcription-scorer) and a subset from [Bayelemabaga](https://huggingface.co/datasets/RobotsMaliAI/bayelemabaga) using the script [process_asr_text_tokenizer.py](../utils/python/process_asr_text_tokenizer.py)
